# Academic Writing Polish

Use this skill as a final pass on paper sections to remove AI-sounding patterns and improve prose quality.

## AI Writing Patterns to Eliminate

### Filler Phrases (delete entirely)
- "It is worth noting that" → just state the fact
- "It is important to note" → just state the fact
- "In this regard" → delete
- "In the context of" → rephrase directly
- "As previously mentioned" → delete or use \cref

### Overused AI Words (replace)
| AI word | Better alternatives |
|---------|-------------------|
| delve | examine, investigate, analyze |
| leverage | use, exploit, apply |
| utilize | use |
| facilitate | enable, allow, support |
| comprehensive | thorough, complete, full |
| significant | substantial, notable, large (or be specific: "40% faster") |
| crucial | important, essential, key |
| robust | reliable, stable, resilient |
| novel | new (or describe what makes it new) |
| paradigm | approach, framework, model |
| synergy | combination, interaction |
| myriad | many, numerous, several |
| plethora | many |
| aforementioned | use \cref or name it |

### Structural Patterns
- Remove "In this section, we..." openers — the section title already says this
- Remove "The rest of this paper is organized as follows" if the structure is obvious
- Don't start consecutive paragraphs with "We" or "The"
- Vary sentence length — mix short declarative with longer explanatory

## Quality Checks
1. Read each paragraph aloud — does it sound like a human expert wrote it?
2. Every paragraph should have a clear topic sentence (usually first)
3. No paragraph should exceed ~8 lines
4. Check for repeated words within 2 sentences
5. Ensure transitions between paragraphs are logical, not formulaic

## Process
1. Read the full section first without changing anything
2. Identify all AI patterns using the lists above
3. Rewrite flagged sentences preserving meaning but improving voice
4. Check that technical precision is maintained after rewrites
5. Verify LaTeX compiles after changes
