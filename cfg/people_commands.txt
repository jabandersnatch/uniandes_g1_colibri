# Colibri G1 People Commands
# ============================
#
# This file defines the behavior of animated characters in the environment.
# Characters execute these commands in sequence and loop indefinitely.
#
# Format: <character_name> <command> <params...>
#
# Available Commands:
#   GoTo <x> <y> <z> <rotation_degrees>  - Walk to position
#   Idle <duration_seconds>              - Stand still
#   LookAround <duration_seconds>        - Look left and right
#
# Coordinate System:
#   x: Forward/backward (-3 to +3 typical)
#   y: Left/right (-3 to +3 typical)
#   z: Height (1.2 for Colibri Lab floor)
#   rotation: Facing direction in degrees (0=forward, 90=left, 180=back, 270=right)
#
# Notes:
#   - Character names must match spawn order: Character_0, Character_1, etc.
#   - Commands are executed sequentially per character
#   - All characters loop their commands infinitely
#   - Positions should stay within spawn area to avoid collisions with walls
